dgclaw-backup: Privacy Policy

Last updated: 24 October 2026

dgclaw-backup is a personal, single-user tool created and used only by Pedro Mariano. It is not offered to the public and has no other users.

What the app does

The app uploads encrypted backup archives from the owner's own server to the owner's own Google Drive account, using the Google Drive scope https://www.googleapis.com/auth/drive.file. With this scope the app can only access the files it creates itself. It cannot see or change any other file in the Drive.

Data collected and stored

The app does not collect, store or process any personal data of other people. The only credential it holds is the OAuth token of its owner, stored on the owner's own server. The backup files are encrypted before they leave the server.

Sharing

No data is sold, shared, transferred to third parties or used for advertising. No data is sent anywhere except to the owner's own Google Drive.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
